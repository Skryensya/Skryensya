## English

I build software for the joy of it, from a full design system to a printer open to the internet and a radio where everyone hears the same song at the same time.

The rest, how I think and why I decide what I decide, is on **[allison.sh](https://allison.sh)**.

### What I'm building now

**[Skryensya/ui](https://github.com/Skryensya/ui)** ([docs](https://ui.skryensya.dev)): a design system where the
contract is the source of truth. React and plain HTML both read it instead of restating it, and a
test renders both in a real browser to check they land on the same DOM, the same accessibility tree
and the same pixels.

### Smaller things, made out of curiosity

- **[Printer](https://github.com/Skryensya/printer)** ([try it](https://ping.allison.sh)): anyone can send a
  short message that prints instantly on the thermal printer on my desk.
- **[Radio](https://radio.allison.sh)**: hand-curated stations, the same song for everyone at the
  same time, no server coordinating anything.
- **[Wada.ink](https://wada.ink)**: the color-combination dictionary the Japanese painter Sanzo Wada
  published in the 1930s, made browsable. Search by name or by similarity, or upload a photo and it
  finds the combinations closest to its palette.

I'm open to talking: contacto@allison.sh
